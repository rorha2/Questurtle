> 언젠가 만들고싶은 기능

## 그려야 할 이미지
 - [] 거북이 정면 (idle)

## 디테일
 - [] 거북이 대사를 한 글자씩 출력
 - [] 개발자 모드(테스트 및 초기화 버튼)
 - [] 우클릭/텍스트 선택 방지

## 기능
 - [] 회원가입 시스템
 - [] 삼성헬스 걸음 수 연동

## 터틀타운 (맵 시스템)
 - [] 마을회관 (퀘스트)
 - [] 가게 (상점)
 - [] 은행 (포인트/환전)
 - [] 공원 (걸음수에 따른 보상)
 - [] 미용실
 - [] 계절 변화 및 그에 따른 테마 제작

## 홈 화면 개편
 - [] 포인트카드 위치 조정
 - [] 간단한 방명록
      ㄴ 프로필카드 하단에 짧은 글 적는 공간
      ㄴ 읽기 전엔 편지봉투, 읽은 후엔 펼쳐진 모양
      ㄴ 작성자, 제목, 내용, 이모지, 선물 남기기 기능
